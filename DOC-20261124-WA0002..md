# Production Workflow — Hyper Sliced AI

One video, start to upload. Check each step off in order.

## Stage 1: Plan (15 min)
- [ ] Read `01-concept/concept.md` and confirm the premise
- [ ] Review `02-storyboard/storyboard.md` (11 shots, ~45s)
- [ ] Confirm the hook (first 2 seconds): looming eraser shadow + "He drew a door… 😭"

## Stage 2: Generate frames (30–60 min)
- [ ] Make the character sheet using `03-ai-prompts/frames-and-motion.md`
- [ ] Generate frames for shots 1–11 with the style block, same seed and reference image
- [ ] Save picks to `assets/frames/` named `shot-01.png` ... `shot-11.png`

## Stage 3: Animate (60–90 min)
- [ ] Image-to-video for each shot (3 takes each), or draw frame by frame on 2s
- [ ] Save best takes to `assets/clips/` named `shot-01.mp4` ...

## Stage 4: Sound (20 min)
- [ ] Gather effects from `04-sound/sfx-cue-sheet.md` into `assets/audio/`
- [ ] Check licenses

## Stage 5: Edit (30–45 min)
- [ ] Follow `05-edit/edit-guide.md` (1080x1920, cuts every 1–2s, loop ending)
- [ ] Export to `assets/exports/stickman-eraser-v1.mp4`

## Stage 6: Approve
- [ ] Complete `checklists/approval.md`

## Stage 7: Upload (10 min)
- [ ] Use `06-upload/upload-package.md` (title, thumbnail, description, tags, pinned comment)
- [ ] Post at your usual time slot

## Stage 8: Review (48 hours later)
- [ ] Check swipe-away rate in the first 3 seconds and average view duration
- [ ] Apply what worked to the next episode (`07-growth/hooks-and-ideas.md`)

## Rough total time
About 3–4 hours per Short once you have a routine.
